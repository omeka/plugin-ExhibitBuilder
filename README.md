# Exhibit Builder

The Exhibit Builder plugin for Omeka Classic allows users to create online exhibits that combine items from the site with narrative text and other content.

Exhibit Builder is one of the default plugins that come bundled with Omeka Classic.

See the [Exhibit Builder page in the Omeka Classic user manual](https://omeka.org/classic/docs/Plugins/ExhibitBuilder) for user documentation.
